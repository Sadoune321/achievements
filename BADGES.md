# Badges de profil GitHub

Liste des badges de profil et comment les obtenir :

- **Pull Shark** : 1 pull request fusionnée (bronze), 16 (argent), 128 (or).
- **Quickdraw** : ouvrir une pull request dans les 5 minutes suivant l'ouverture de l'issue associée.
- **YOLO** : fusionner une pull request sans revue de code.
- **Starstruck** : votre dépôt atteint 16 étoiles.
- **Galaxy Brain** : réponse acceptée dans une discussion GitHub.

Voir aussi les [conditions d'attribution](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/managing-contribution-settings-on-your-profile/showing-your-private-contributions-and-achievements-on-your-profile).
