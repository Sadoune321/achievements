# Contribuer

Merci de l'int,er. Ce repo regroupe des notes et démonstrations de développement.

## Comment proposer une modification

1. Créez une branche descriptive : docs/xyz
2. Faites un petit commit ciblé
3. Ouvrez une pull request : un changement = une PR
4. La PR est mergée sans relecture si le changement est trivial

## Convention de commit

- docs: pour la documentation
- eat: pour une nouvelle démonstration
- ix: pour une correction
